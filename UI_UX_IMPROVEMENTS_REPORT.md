# 🎨 UI/UX Покращення для Report Generation Dialog

## 📋 Аналіз поточних проблем

### Проблеми:
1. **Progress Stepper** - занадто простий, не показує зв'язок між кроками
2. **Step 1 (Scope)** - радіо-кнопки виглядають однаково, немає візуальної ієрархії
3. **Step 2 (Options)** - довгий список чекбоксів, важко швидко зрозуміти що включено
4. **Step 3 (Preview)** - обмежений перегляд, тільки одна сторінка
5. **Step 4 (Generating)** - мінімальна візуалізація прогресу
6. **Загальні** - немає підказок, підтверджень, візуальних акцентів

---

## 🎯 Додаткові покращення

### A. Валідація та підказки
- Показувати попередження якщо вибрано занадто багато assets
- Підказки про розмір файлу при включенні photos
- Рекомендації на основі вибору

### B. Keyboard Navigation
- Tab для навігації між полями
- Enter для переходу до наступного кроку
- Escape для закриття
- Стрілки для навігації в preview

### C. Responsive Design
- Адаптація для мобільних пристроїв
- Вертикальний stepper на малих екранах
- Оптимізація preview для різних розмірів

### D. Accessibility
- ARIA labels для всіх інтерактивних елементів
- Focus management між кроками
- Screen reader support

### E. Performance
- Lazy loading для preview сторінок
- Оптимізація рендерингу великих списків
- Debounce для live preview updates
