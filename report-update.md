## 🎯 Огляд

Додано комплексну систему валідації інспекцій та функції експорту/перенесення проектів. Реалізовано повний флоу від вибору опцій до відображення результатів з можливістю масового виправлення помилок.

---

## ✨ Нові функції

### 1. Валідація інспекцій

**Компоненти:**
- `ValidationDialog.tsx` - Діалог вибору опцій валідації
- `ValidationProgressDialog.tsx` - Діалог з прогресом валідації
- `ValidationResultsDialog.tsx` - Діалог з результатами валідації
- `ValidationErrorsView.tsx` - Детальний перегляд помилок
- `BulkFixDialog.tsx` - Діалог масового виправлення помилок

**Функціональність:**
- Вибір scope (всі assets / вибрані assets)
- Налаштування правил валідації:
  - Required fields completed
  - Valid PACP/NASCO codes
  - Access points present (minimum 2)
  - Inspection dates valid
  - Certificate numbers present
- Додаткові дії (verify media, rename media)
- Відображення прогресу в реальному часі
- Детальний список помилок з можливістю фільтрації
- Масове виправлення помилок

### 2. Експорт проекту

**Компонент:** `ExportProjectDialog.tsx`

**Функціональність:**
- Вибір формату експорту:
  - CSV (Spreadsheet data only)
  - Excel (Formatted workbook)
  - PDF (Formatted report)
  - ZIP (Complete archive with media)
- Налаштування включених даних:
  - Inspection data
  - Observations
  - Photos
  - Videos
  - GIS shapefiles
  - Certificates
- Вибір scope (всі / поточний view / вибрані)
- Розрахунок очікуваного розміру файлу
- Відображення прогресу експорту
- Діалог успіху з деталями експортованого файлу

### 3. Перенесення в проект

**Компонент:** `MoveToProjectDialog.tsx`

**Функціональність:**
- Вибір проекту призначення
- Опції перенесення:
  - Move inspection data
  - Move observations
  - Move media files
  - Preserve timestamps
  - Move assignments
- Підтвердження з попередженням
- Автоматичне видалення assets з поточного проекту після перенесення

### 4. Копіювання в проект

**Компонент:** `CopyToProjectDialog.tsx`

**Функціональність:**
- Вибір проекту призначення
- Опції копіювання:
  - Copy inspection data
  - Copy observations
  - Copy media files
  - Copy timestamps
  - Copy assignments
  - Link to original (reference only)
- Assets залишаються в поточному проекті
- Створення незалежних копій
