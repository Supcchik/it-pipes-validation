# План реструктуризації роутингу

## Мета
Змінити структуру роутів так, щоб:
- `localhost:3000/` → відкривалась сторінка зі списком інспекцій (AssetListPage)
- `localhost:3000/inspection/[id]` → відкривалась сторінка з деталями інспекції (InspectionPage)

## Поточна структура
```
app/
  ├── page.tsx              → InspectionPage (деталі інспекції)
  ├── assets/
  │   └── page.tsx          → AssetListPage (список інспекцій)
  └── layout.tsx
```

## Цільова структура
```
app/
  ├── page.tsx              → AssetListPage (список інспекцій) ✨ НОВИЙ
  ├── inspection/
  │   └── [id]/
  │       └── page.tsx      → InspectionPage (деталі інспекції) ✨ НОВИЙ
  └── layout.tsx
```

**Ризик:** Низький

3. Оновити логіку отримання даних інспекції (замість хардкоду)

**Файл:** `/app/inspection/[id]/page.tsx`
**Зміни:**

- Додати `const params = useParams(); const inspectionId = params.id as string;`
